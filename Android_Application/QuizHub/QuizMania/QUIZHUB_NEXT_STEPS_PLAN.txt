QUIZHUB – STEP-BY-STEP ACTION & EXECUTION PLAN
AI-Powered Adaptive Learning & Quiz Management Android Application
================================================================================

Now that QuizHub has been built, all Java classes, XML layouts, drawables, 
and algorithms have been written, and the APK has compiled successfully, 
follow this clear, step-by-step guide to run, test, verify, and present the app.

--------------------------------------------------------------------------------
STEP 1: FIREBASE CONSOLE VERIFICATION (ONE-TIME SETUP)
--------------------------------------------------------------------------------
QuizHub is connected to Firebase using your existing configuration:
- Project ID: quizmania-25861
- Package Name: com.example.quizmania

Verify the following in the Firebase Console (https://console.firebase.google.com):
1.1. Go to "Authentication" -> "Sign-in method":
     - Ensure "Email/Password" is ENABLED.
1.2. Go to "Firestore Database":
     - Ensure Cloud Firestore is created/active.
     - In the "Rules" tab, copy and paste the rules from the project's
       `firestore.rules` file and click "Publish".
     - Note: Default sample subjects and questions will automatically seed 
       on first run if your Firestore collections are empty!

--------------------------------------------------------------------------------
STEP 2: RUN THE APP ON A DEVICE OR EMULATOR
--------------------------------------------------------------------------------
2.1. In Android Studio:
     - Open the QuizMania project.
     - Select a connected physical Android device (via USB/Wi-Fi debugging) 
       or an Android Virtual Device (AVD Emulator with API 24+).
     - Click the green "Run" button (Shift + F10).
2.2. Alternatively, install the pre-compiled APK directly:
     - The debug APK is located at:
       app\build\outputs\apk\debug\app-debug.apk
     - Run in PowerShell/Terminal:
       adb install -r "app\build\outputs\apk\debug\app-debug.apk"

STEP 5: TEST THE 5-ATTEMPT ADAPTIVE LEARNING ENGINE (CORE DIFFERENTIATOR)
--------------------------------------------------------------------------------
This is the most critical feature of QuizHub:
5.1. Attempt quizzes in the SAME subject (e.g. Java Programming) 5 times:
     - Attempt 1 -> Complete
     - Attempt 2 -> Complete
     - Attempt 3 -> Complete
     - Attempt 4 -> Complete
     - Attempt 5 -> Complete
5.2. Open "Adaptive Revision" from the Student Dashboard:
     - Observe the 5-Step visual indicator updating (1 -> 2 -> 3 -> 4 -> 5).
5.3. On completion of Attempt 5:
     - Observe the automated trigger: A personalized revision quiz is generated!
     - Check the Student Dashboard: A prominent yellow alert banner appears:
       "Adaptive Revision Ready! 5/5 Attempts completed. Practice your weak spots now."
5.4. Open the Mistake Notebook:
     - Verify historical wrong answers are listed with:
       * Question snapshot
       * Your selected answer (highlighted in red)
       * Correct answer (highlighted in green)
       * Answer explanation
       * Mastery Badge: "Weak"
     - Tap "Practice Again" to test quick single-question practice.
5.5. Attempt the Personalized Revision Quiz:
     - Tap "Start Revision Quiz".
     - Notice that all questions are deduplicated questions from your mistakes.
     - Answer the questions correctly.
     - Submit the revision quiz.
     - Observe the Completion Milestone dialog:
       * Displays before/after accuracy improvement (+X percentage points!).
       * Questions answered correctly in revision advance from "Weak" -> "Practicing" -> "Mastered".
